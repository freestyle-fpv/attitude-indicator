# caldiag3 硬件诊断验证

2026-11-22，连接本项目的 Waveshare ESP32-S3-Touch-AMOLED-1.75 实测。该结果只适用于本次连接的开发板，不能代表反馈者的故障板已经修复。

| 项目 | 实测 |
| --- | --- |
| 高频 IMU 消息 | 最终版本约 20.0 Hz |
| 正常圆形姿态仪 | 40.5–41.5 FPS（观察窗口） |
| IMU 身份与配置 | 地址 0x6B，WHOAMI=0x05，修订 124，CTRL2/3/7=0x15/0x65/0x03 |
| IMU 通信 | 通信失败、短读、饱和均为 0 |
| 加速度计内置自检 | 通过；响应 780.5 / 619.5 / 580 mg |
| 陀螺仪内置自检 | 通过；响应约 1131.25 / 1111.31 / 1212 °/s |
| 自检恢复 | 配置恢复，随后重新完成 400 样本校准，姿态重新有效 |
| 内部 RAM | 临时连续 8 KB 区域图案写读通过；16 KB 申请因连续空间不足而自动缩小 |
| PSRAM | 临时 64 KB 区域图案写读通过 |
| 运行程序镜像 | SHA-256 镜像校验通过 |
| 电源与外设 | AXP2101、触摸及扩展器可通信；USB 约 5.190 V，系统约 3.746 V；未接电池 |
| RTC | 可通信、秒字段推进，停振历史标志为 1；提示时间可能失效，不改写时间 |
| 音频接口 | ES8311 与 ES7210 均可读；未进行录放音测试 |
| SD 卡 | 本轮未插卡执行读卡测试，网页明确标为未检测 |

原始捕获位于本地 `build/hardware-serial-live.json`、`build/hardware-serial-live.log`，带时间的导入日志为 `build/hardware-serial-report.txt`。高频输出中未出现发送丢弃。自检期间主动暂停采样并重新校准，临时的显示状态和 FPS 与正常姿态显示不同。

自动测试覆盖自检握手、超时、通信失败、正确的 CTRL7 地址 0x08、带符号响应解码、手册阈值、配置恢复、临时内存越界保护、高频调度及租期，另包含原有采样恢复和绘图回归。浏览器检查覆盖中文状态、模拟串口命令、静止统计、单页切换保留连接、旧日志兼容、过期数据、示例隔离及窄屏布局。

报告导出经浏览器实际下载验证，生成非空 TXT 文件；新增报告预览、明确的下载请求提示、再次下载与复制备用入口。验证前保存了用户正在采集的实测报告，更新页面后按历史日志恢复，未将它冒充为当前实时数据。

屏幕坏点/颜色、触摸全区域及真实按键逐项动作未在本轮人工复核。没有进行供电纹波测量、整片存储器破坏性测试或外部仪器精度校验。
