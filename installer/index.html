安装航模座舱仪表

仅适用于 Waveshare ESP32-S3-Touch-AMOLED-1.75。

  1. 在电脑上用 Chrome 或 Edge 打开本页，用 USB 数据线连接开发板。
  2. 点击下方按钮，选择新出现的 USB 串口，再依次点击 Install → Next → Install。
  3. 看到 Installation complete! 后关闭本页。按实际方向装好开发板，让模型保持水平静止，再重新上电；仪表会自动校准，无需按键。

正在加载安装器…

请在电脑上的 Chrome 或 Edge 打开此文件。 请把安装页解压出来，再用 Chrome 或 Edge 直接打开。
首次安装与保留设置

安装会替换板上的程序。从出厂测试程序换装时，可在确认窗口选择 Erase device 清除旧数据。重装本项目时，保持该选项未勾选即可保留安装方向和 FPS 设置。

若烧录时已在桌面完成自动校准，装回座舱后请让模型保持水平静止，短按 PWR 重新校准，或重新上电自动校准。

没有找到串口或连接不上

先关闭 Arduino 串口监视器等占用串口的程序，再重新插拔 USB 数据线。如果仍然连不上，让板子完全断电，按住 BOOT 再重新上电，等串口出现后松手并重试。
