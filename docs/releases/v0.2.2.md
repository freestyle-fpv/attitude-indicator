# v0.2.2 · 保存首次校准，简化安装流程

首次校准成功后，仪表保存陀螺仪零偏和安装零点，后续开机直接恢复，不再重复等待约 2 秒的静止校准。校准允许有界轻微抖动，安装器更新至 r6。

## 下载与安装

下载 **Attitude-Indicator-v0.2.2-USB-Installer-r6.zip**，解压后在电脑 Chrome 或 Edge 打开 **安装器.html**。

1. 用 USB 数据线连接开发板，点击「安装固件」并选择串口。
2. 默认不勾选「清除设备数据」，依次点击「下一步」→「安装」。
3. 安装完成后点击右下角「关闭」，串口自动交回设备诊断。
4. 首次没有保存记录时，按实际安装姿态让模型水平静止，等待校准完成并保存。如果在桌面已完成首次校准，装回座舱后短按 PWR 更新零点。

仅适用于 **Waveshare ESP32-S3-Touch-AMOLED-1.75**。安装包包含固件、烧录工具、表盘图片和中文诊断，可离线使用；源码 ZIP 不是一键安装包。

## 校准保存与恢复

- 四个安装方向分别保存记录，正常开机恢复当前方向的零偏与安装零点；倾斜开机不会把当前倾角重新当作零点。
- PWR / 串口 `c`、安装方向变更及 IMU 自检后的新校准成功时更新记录。
- 记录通过格式版本、方向、CRC32 和数值检查；记录缺失或损坏时重新校准。
- 网页诊断新增「校准数据存储」，用中文区分已恢复、等待保存、已保存和失败。
- 重新安装时不清除设备数据即可保留设置和校准；选择清除数据会删除保存记录。

## 轻微抖动容忍度

| 检查项 | v0.2.1 | v0.2.2 |
| --- | --- | --- |
| 4 样本平均陀螺仪与累计均值的合成差 | 0.75°/s | **5°/s** |
| 平均加速度向量相对首个采样块的变化 | 0.025g | **0.05g** |
| 原始三轴合成角速度上限 | 10°/s | 10°/s，保留 |
| 单样本加速度向量变化上限 | 0.075g | 0.075g，保留 |

加速度模长仍需在 0.85–1.15g 开区间内，首次或手动校准仍需完整 400 样本。**5°/s 是均值变化门槛，原始角速度上限仍为 10°/s。**诊断页读取设备报告的实际门槛；旧固件没有新字段时不推定已经使用新条件。

## 安装器 r6

- 跳过「安装 / 串口日志」选择菜单，选好串口后直接进入清除数据选项。
- 保留最终安装确认，清除数据默认不勾选。
- 安装完成后的「关闭」按钮关闭弹窗并恢复原串口诊断；确认页返回、取消及失败重试不会回到旧菜单。

## 验证与限制

- 8 项安装器启动场景、37 项网页诊断测试、7 项打包测试及完整 C++ 主机回归通过；C++ 使用 ASan / UBSan。
- ESP32-S3 构建、离线安装包完整性、内嵌固件一致性和 SHA-256 检查通过。
- 浏览器使用同一烧录组件检查了模拟安装完成态与关闭动作；本轮没有实际烧录或实板断电恢复、温漂及飞行复测。
- 温度变化可能改变陀螺仪零偏，出现漂移时仍需 PWR 手动校准。校准时仍应尽量固定，不能把持续转动当作静止。
- 空速、高度和航向仍为模拟数据，真实姿态来自板载 IMU。
