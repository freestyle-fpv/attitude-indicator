# 空速表开发与刷新验证

日期：2026-09-10。开发板：ESP32-S3-Touch-AMOLED-1.75，466×466 CO5300，40 MHz QSPI；USB 在左侧。固件默认显示 0–200 km/h 空速表，短按 BOOT 切换姿态仪；空速为模拟输入，持续标记 SIM。

## 本次修复

- 静态表盘只在进入仪表或刷新代次变化时整屏初始化。正常运动只恢复并更新新旧指针及阴影覆盖区域。
- 背景缓存复制、定点指针绘图和 DMA 传输按三个独占缓冲槽流转，背景与传输在 core 0，前景在 core 1；DMA 完成后才复用对应内存。
- GPIO 13 接收 CO5300 的 TE 信号。整块指针区域先完成绘图，再等新的垂直消隐脉冲提交；等待超时 30 ms 会回退并累计诊断计数。
- 修正局部刷新仅对齐横向的遗漏。窗口横纵起点均为偶数，包含的宽高均为偶数。FPS 在底部仍然居中，传输时包入额外边界列以满足屏幕对齐。

Waveshare 官方 BSP 对两轴的对齐处理：[rounder_event_cb](https://github.com/waveshareteam/Waveshare-ESP32-components/blob/9daffb7168b3c093a330da700988a22092294eef/bsp/esp32_s3_touch_amoled_1_75/esp32_s3_touch_amoled_1_75.c#L393-L408)。

## 软件验证

- `sh tools/airspeed_test.sh`：量程限幅、0/100/200 指针方向、非有限输入、native/wire 字节序、任意分带、局部更新重建和缓冲区保护通过。新增两轴对齐断言在修复前失败、修复后通过。
- `sh tools/test.sh`：姿态解算、校准、安装轴向、原有绘图/阴影、日志、FPS、圆形分带与传输回归通过。
- `sh tools/renderer_stages_test.sh`：199 个姿态与冻结参考一致；跨线程/分带/保护区域通过。
- `sh tools/fast_panel_test.sh --prove-regression`：1024/2048/4096 宏配置各 56 个窗口，包含 PSRAM 复制路径；命令、坐标、像素载荷、DMA 描述符与缓冲区生命周期通过。移除 DMA 上限的故障版本被测试拒绝。
- `sh tools/build.sh`：ESP32 固件编译通过（程序 556,398 字节，静态 RAM 35,044 字节）。
- `sh tools/flash.sh /dev/cu.usbmodem21101`：已烧录，写入哈希校验通过。
- C++ 实际画面已导出并与 HTML 设计稿核对；指针阴影、量程、边缘色带和数字密度保留。

## 实物测量

| 模式 | FPS 范围 | FPS 中位数 |
| --- | --- | --- |
| 空速 0 km/h | 55.7–56.7 | 55.7 |
| 空速 200 km/h | 55.7 | 55.7 |
| 真实姿态（静止） | 42.1 | 42.1 |
| 姿态演示 | 35.7–37.5 | 36.2 |
| 空速 135 km/h | 55.7–55.8 | 55.8 |
| 空速自动演示（65 秒） | 54.7–60.8 | 59.6 |

上表剔除每个阶段最初两个样本，避免切换前后的 FPS 统计窗口混合。65 秒连续演示的全部 64 个样本（含切换过渡）为 52.8–60.8 FPS。TE 周期约 16.48 ms（60.7 Hz），全部空速阶段的同步等待超时计数为 0。

连续演示绘图 12.2–19.0 ms，传输 3.3–7.5 ms，二者重叠执行；IMU 采样 198.6–201.4 Hz，剩余堆内存 18,116–18,160 字节。内存有 44 字节变化，未见持续下降或重启。模式切换产生过 82.3 ms 的最大帧间隔，该值不代表稳定演示帧间隔。

量程两端、手动设速、仪表切换和独立演示状态均已验证；测试结束保持空速自动演示。原始秒级日志及烧录文件 SHA-256 保存在 `airspeed-board-measurements.json`。FPS 按实际完成的显示更新计数，包含绘图、排队、同步等待和传输。
