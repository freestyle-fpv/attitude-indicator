# 网页安装与诊断终端

保留当前离线安装体系，在现有 checkout 内完成，不创建云端网站或自动发布。用户已要求直接开发，按当前 caldiag1 固件字段实现。

1. 新增浏览器与 Node 共用的诊断核心。先测串口分包、CRLF、非法数值、旧版性能日志、诊断拒绝原因、过期数据、有限日志容量、端口取消/拔出/关闭与校准指令，再实现。
2. 构建设备诊断页：Web Serial 115200、明确的示例模式、校准进度、IMU 状态、三轴陀螺仪趋势、故障计数、中文解释、原始日志、导入与导出。只在用户点击时连接或发送校准命令。串口内容按纯文本显示。
3. 安装页采用同一套深色青绿维护终端风格，保留既有启动诊断和烧录流程。离线包内两页互相链接，资源全部内联，无 CDN。
4. 扩展打包回归，核对两页独立工作、离线资源和固件哈希；运行完整主测试、网页桌面/窄屏功能和视觉检查。提供本地预览与新的诊断 ZIP，不自动推送 GitHub。

检查重点：断开的历史数据不能当成当前健康数据；示例数据不可混入真实采集；最新拒绝原因不能被误说成已证实的硬件故障；读循环取消时先释放 reader 再关闭端口；烧录与诊断不能同时占用串口；源码模板不能显示可烧录状态。

## 安装器 r4 整合

按用户网页标注合并为一个 `安装页器.html`，导航只切换可见区，保留同一串口对象与日志。安装前释放流锁并暂交 ESP Web Tools，关闭安装窗口后在同一授权端口恢复读取；USB 拔出/系统重枚举使句柄失效时显示重新连接提示。固定版本库只修改界面中文文本和主题，保留原烧录协议及固件分段。

删除参数表，加入四表盘自动轮播、箭头/圆点/键盘切换、悬停和聚焦暂停，以及减少动态效果偏好。用固件绘图器重新输出截图，不显示 FPS 和 SIM；实际固件行为不改。最终 ZIP 只含一个 HTML 和说明/许可证。

验证：启动失败提示，串口读锁交接/取消/异常/拔出恢复，四图片离线内联，全套原生回归，桌面与窄屏轮播及诊断，中文擦除和安装确认。浏览器安装流程使用标明的内存模拟串口检查，不执行真实烧录。
