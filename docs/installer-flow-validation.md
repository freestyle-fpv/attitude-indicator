# 安装器 r6 弹窗流程验证

日期：2026-11-23。固件仍为本地测试版 `v0.2.2-persist`，本次只调整安装器 UI 导航。

- 选择串口后直接进入「清除设备数据」，不再显示安装/日志选择菜单。
- 清除数据默认不勾选，选项仍交给最终安装确认处理；跳过菜单不会自动烧录。
- 清除选项页的「返回」关闭窗口；安装确认页的「返回」回到清除选项。
- 安装完成后的右下角按钮为「关闭」，沿用原组件关闭事件与串口交接流程。
- 安装失败后的重试回到清除选项，不再回到旧菜单。

验证：完整 `sh tools/test.sh` 通过，包含 37 项网页诊断测试、7 项打包测试及原生 C++ 回归。打包测试提取固定版本 ESP Web Tools 10.5.2 的真实 UI 方法执行构造、按钮回调和关闭事件，并与实际 `SerialConnection.install()` 组合验证串口选择只发生一次。源码结构不匹配时转换失败，不静默生成错误流程。

浏览器使用与安装包相同的烧录组件，在明确标注的无硬件模拟页确认首次直接显示清除选项、完成页显示「关闭」、点击后触发关闭事件并移除窗口。模拟完成态不代表实际烧录；本轮没有写入开发板。侧边正式安装页已刷新到 r6。
