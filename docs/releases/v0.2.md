# v0.2 · 中文硬件诊断与单页安装器

本版重点增加设备硬件诊断，帮助定位刷入程序后一直停在校准页面的问题，同时整合离线安装流程。

## 安装

下载 `Attitude-Indicator-v0.2-USB-Installer-r5.zip`，解压后用电脑 Chrome 或 Edge 打开 **安装器.html**。连接 Waveshare ESP32-S3-Touch-AMOLED-1.75，点击「安装固件」并按中文提示操作。

重装时不勾选「清除设备数据」，可保留安装方向和 FPS 设置。安装结束后关闭安装窗口，即可切换到同页的「设备诊断」；正常情况下无需重新选择串口。USB 重新插拔或系统重新枚举后可能需要重连。

## 新增与改善

- 安装与诊断合并为单个离线 HTML，内嵌固件、烧录工具和资源；安装弹窗中文化。
- 四种表盘截图自动轮播，支持手动切换；预览移除 FPS 和 SIM 标记。
- 中文硬件检测：IMU 身份、配置、温度、时间戳，通信失败、短读、饱和、未就绪与校准拒绝原因；同时显示电源电压、触摸和按键事件、显示同步、系统资源与 RTC/音频接口状态。
- 增加 IMU 加速度计、陀螺仪内置自检，以及 10 秒静止数据统计。自检结束后恢复配置并重新校准，原有校准条件保持不变。
- 提供临时 RAM / PSRAM 图案检查、运行程序镜像校验，以及手动 SD 卡只读识别。
- 诊断数据按需以约 20 Hz 更新，硬件状态约 1 Hz；订阅超时自动停流，串口发送保持零等待。
- 导出报告显示预览、下载提示，支持再次下载和复制；兼容导入历史日志，明确区分示例与实机数据。
- 固件启动和 IMUDIAG 日志标注发布版本 `v0.2`，诊断协议版本为 `caldiag3`。

## 验证与范围

发布前执行主机回归、ESP32-S3 编译及安装包校验。caldiag3 功能已在同型号开发板实测：诊断流约 20 Hz、正常圆形姿态仪约 40 FPS，IMU 自检、恢复校准、内存抽检和运行程序镜像校验通过。报告导出经过浏览器实际下载验证。

新增的是故障定位能力，尚未确认反馈者的校准问题已经修复。建议固定静止后采集 10 秒数据，运行 IMU 自检，再导出报告反馈。

内存仅抽检临时区域；SD 只检查识别和首扇区读取，不格式化、不写文件。屏幕坏点、颜色、触摸全区域、按键实际动作、音频录放及射频性能仍需相应人工或外部测试。完整说明见仓库 README 和诊断文档。
