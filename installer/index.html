一块圆屏，四种飞行视角。

为固定翼 FPV 座舱打造的开源仪表。连接 USB，将圆形姿态仪、HUD、空速表和高度计装进你的飞机。

把仪表装进开发板

Waveshare ESP32-S3-Touch-AMOLED-1.75

  1. 连接开发板在电脑 Chrome 或 Edge 打开本页，使用 USB 数据线连接开发板。
  2. 选择串口并安装点击下方按钮，选择开发板的 USB 串口，按中文提示确认并安装。已连接诊断的设备可直接安装。
  3. 装好，静止，重新上电看到「安装完成」后关闭安装窗口，即可直接切换到设备诊断。按实际方向装好开发板，让模型保持水平静止，再重新上电；仪表会自动校准。

安装器尚未启动。请在电脑上用最新版 Chrome 或 Edge 打开，并允许 JavaScript 运行。

重装时不勾选「清除设备数据」，可保留安装方向和 FPS 设置。

首次安装与校准
安装会替换板上的程序。从出厂测试程序换装时，可在确认窗口选择「清除设备数据」清除旧数据。重装本项目时，保持该选项未勾选即可保留设置。
若烧录时已在桌面完成自动校准，装回座舱后让模型保持水平静止，短按 PWR 重新校准，或重新上电自动校准。
没有串口，或校准一直不动
先关闭其他串口工具，重新插拔 USB 数据线。仍无法连接时，完全断电，按住 BOOT 再重新上电，等串口出现后松手并重试。
能够启动但校准进度长期为零？使用设备诊断查看实时读数，并导出报告反馈。


空速、高度与航向目前为模拟数据；真实姿态来自板载六轴 IMU。仅适用于上方指定板型。

检测覆盖范围与人工检查
自动检查 IMU 身份、配置、温度、通信和采样，读取电源管理、触摸及按键接口、显示同步和系统资源。手动检测可运行 IMU 电静力自检、RAM 最多 16 KB（连续空间不足时缩小） / PSRAM 最多 64 KB 临时区图案检查、运行程序镜像校验。
