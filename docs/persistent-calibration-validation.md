# 首次校准保存与开机恢复验证

日期：2026-11-23。测试版本：`v0.2.2-persist`，未发布。

## 已验证的软件行为

- 无保存记录时仍需完整 400 样本；首次成功后只投递一次保存请求。
- NVS 适配器按方向保存、回读并校验记录；长度、CRC32、格式版本、方向及数值不合法时拒绝恢复。
- 已保存记录的启动不再采集静止窗口；当前倾角不会成为新零点。测试包含保存 20° 安装横滚后以 50° 横滚开机，读数为相对 30°，以及组合俯仰/安装横滚。
- 保存的陀螺仪零偏用于后续积分；禁用加速度修正的回归没有依赖重力修正掩盖漂移。
- 四个方向分别恢复；PWR/串口请求和 IMU 自检后必须完成新校准，不能再次套用启动记录。
- 无 IMU 或尚无可信新读数时，保存记录不能授权有效姿态。
- 主循环执行一次 NVS 写入和回读，采样任务不访问 Preferences。校准窗口 token 保证旧保存结果不能覆盖新请求的诊断状态。
- 网页中文解释已恢复、等待保存、已保存和失败；旧固件没有保存状态时不推定通过。

## 实体验证范围

本轮尚未烧录，也没有实际断电测试。主机回归模拟存储 I/O 和重启，不等同于实体 NVS 断电保存或温漂验证。

实板复测时，先按实际安装姿态完成校准并确认诊断显示已保存，再断电重启；无需重新等待 400 样本，轻微倾斜开机应保留相对倾角。PWR 新校准成功后再次断电，检查恢复的是新零点。温度变化导致的零偏漂移仍需手动重新校准。
