# v0.2.1 · 放宽静止校准的原始陀螺仪上限

修复部分板卡静止时原始陀螺仪零偏较大、校准进度一直为 0/400 的问题。三轴合成速率上限由 5°/s 调整为 **10°/s**；保留 0.75°/s 变化门限、0.85–1.15g 重力范围、加速度稳定检查和 400 样本要求。

## 安装

下载 `Attitude-Indicator-v0.2.1-USB-Installer-r5.zip`，解压后在电脑 Chrome 或 Edge 打开 **安装器.html**。按中文提示安装；重装时不勾选「清除设备数据」可保留安装方向和 FPS 设置。安装后让模型按实际方向保持水平静止，等待自动校准完成。

本版沿用安装器 r5 和 caldiag3 诊断协议。固件启动版本及安装页版本为 `v0.2.1`。

## 变更

- 原始陀螺仪三轴合成上限从 `0.08726646 rad/s` 调整为 `0.17453293 rad/s`，即 5°/s → 10°/s。
- 网页静止窗口统计同步使用 10°/s，拒绝说明区分 v0.2.1 与较早版本的门限；超限示例同步调整。
- 增加报告中的约 5.29°/s 三轴偏置及小幅噪声回归，确认收满 400 样本后估计偏置。
- 直接运行固件采样任务的主机回归确认：该偏置可校准，后续积分会扣除偏置，关闭重力修正时也没有持续漂移。
- 验证 9.99°/s 可完成静止校准，10.01°/s 及每轴 6°/s、合成超过 10°/s 的读数仍会拒收并重置。

## 验证与限制

- 8 项安装器启动场景、34 项网页诊断测试、5 项打包测试通过；完整 C++ 主机回归在 UBSan 下通过。
- ESP32-S3 编译通过；安装包核验固件分段、内嵌资源、版本和 SHA-256。
- 本机 ASan 在空程序上也出现初始化故障，未计为通过；本轮 C++ 回归使用 UBSan。
- 本轮没有连接开发板，尚未完成反馈者故障板的实际刷写、静止漂移、振动及飞行复测。软件回归通过不代表已确认该板硬件正常。
- 校准仍要求保持静止。PWR 误触发、电源读数及芯片表面异常需要单独排查，本版没有改变相应电路或按键判定。
