# 保存首次校准并在开机恢复

用户要求：首次烧写后校准一次并保存，以后正常开机不再重新采集静止样本；PWR 手动校准仍可更新数据。

沿用 ESP32 Preferences/NVS，四个安装方向各用一个带格式版本、方向、CRC 的记录，保存陀螺仪零偏及校准时平均重力向量。没有记录、校验失败或数据不合理时才重新采集 400 个样本。正常重装保留 NVS，因此也保留校准；选择清除设备数据才强制首次校准。方向切换沿用现有行为，重新校准并替换该方向记录。

启动不能把当前姿态重新当作零点。先从保存的重力向量恢复安装零点，再根据当前可信重力读数初始化当前姿态，继续减去保存的陀螺仪零偏。IMU 未就绪、读数失效或不可信时不得输出有效姿态。六轴 IMU 无法恢复绝对航向；温度变化造成的陀螺仪零偏漂移仍需手动重新校准。

采样任务只投递一次保存请求；主循环负责 NVS 写入及回读验证，避免在 200 Hz 的采样任务中执行 Flash 操作。失败不伪称已保存，诊断页和原始日志说明状态。仅成功的新校准覆盖旧记录，校准中断不会抹掉上次成功的记录。

考虑过每次上电校准（与需求冲突）、只存单一方向（容易误用安装零点），选择每方向独立记录。现有 5°/s 变化门槛、10°/s 原始上限和绘图逻辑保持。

此实现可由主机回归与 ESP32 编译验证；真实断电保存、温漂和晃动表现需在实体板上验证。不自行发布或提交远端。
